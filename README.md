# Менеджер паролей в Telegram Bot

![PyPI - Python Version](https://img.shields.io/pypi/pyversions/aiogram?logo=python)

## О проекте

Хранение паролей в зашифрованном виде прямо в Telegram. Добавление, редактирование и удаление пароля с возможностью сгенерировать новый пароль. Используется двухфакторная авторизация по Telegram-ID и Мастер-пароль. Имеется функция экспорта/импорта паролей в XML формат.

💾 База данных SQLite3

🔐 Шифрование AES-256-GCM

## Установка

Клонирование репозитория с помощью SSH‑ключа:

```bash
git clone git@github.com:moreportiro/Password-manager.git
```

Создание виртуального окружения:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Установка зависимостей проекта:

```bash
pip install -r requirements.txt
```

Создание файла `.env` в корневой папке:

```python
BOT_TOKEN = 'token_bot'
ADMIN_ID = telegram_id
```

Не рекомендуется изменять названия переменных, а только вписать свои значения.

## Начало

При вводе команды `/start`, определяется существует ли пользователь в БД или нет. В случае нового пользователя добавляется `telegram-ID` в таблицу `User`.

## Мастер-пароль

Если у пользователя отсутствует **Мастер-пароль**, доступ к командам запрещён.
Необходимо установить **Мастер-пароль** в соответствии с требованиями (8 символов, буквы+цифры, спецсимволы, нижний+верхний регистр).

**Мастер-пароль** запрашивается при каждой новой сессии. Во время сессии **Мастер-пароль** хешируется.
В случае потери **Мастер-пароля**, необходимо нажать на кнопку `🔄 Забыли пароль?`, которая запустит алгоритм сброса **Мастер-пароля**:

1. Подтвердить сброс написав `ПОДТВЕРЖДАЮ СБРОС`.
2. Вписать новый **Мастер-пароль** в соответствии с требованиями.

После сброса **Мастер-пароля** все добавленные пароли пользователя будут удалены навсегда.

## Добавление пароля

При нажатии на кнопку `➕ Добавить пароль` запускается алгоритм заполнения:

1. Вписать название **Сайта/Сервиса** (1-150 символов).
2. Вписать **Логин** (1-200 символов).
3. Вписать/Сгенерировать **Пароль** (4-200 символов).

После успешного заполнения данные шифруются и добавляются в таблицу `Password`. Данные в таблице `Password` привязываются к конкретному `telegram-ID`.

## Генерация пароля

При нажатии на кнопку `🎲 Сгенерировать пароль` генерируется случайная комбинация из 16 символов. Используется экранирование пароля при отображении.

При нажатии на кнопку `🔄 Сгенерировать другой` генерируется новая случайная комбинация из 16 символов.

В случае когда сгенерированный пароль уже не требуется, следует нажать на кнопку `📝 Ввести свой пароль`, для ввода вручную.

## Сброс пароля

При нажатии на кнопку `🔄 Заменить пароль` запустится алгоритм сброса пароля:

1. Вписать **Логин** (если не требуется, используется команда `/skip`).
2. Вписать/Сгенерировать **Пароль**.

После успешного заполнения данные шифруются и заменяются в таблице Password.

## Экспорт и импорт паролей (XML)

При нажатии на кнопку `📤 Экспорт XML` бот создаёт файл `passwords_<id>.xml` со всеми сохранёнными паролями (в открытом виде – расшифрованными). Это удобно для резервного копирования или переноса данных.

При нажатии на кнопку `📥 Импорт XML` бот попросит отправить XML-файл, экспортированный ранее.

При импорте:
- Добавляются только новые записи (по названию сайта).
- Существующие пароли не изменяются и не удаляются.
- Дубликаты автоматически пропускаются.

## Прочее

При нажатии на кнопку `🗑️ Удалить пароль` отобразятся все добавленные **Сайты/Сервисы**,
 **Сайта/Сервиса** пароль навсегда удалится.

При нажатии на кнопку `🔐 Мои пароли` отобразятся все добавленные **Сайты/Сервисы**,
 **Сайта/Сервиса** отобразятся данные: **Название**, **Логин**, **Пароль**.

При нажатии на кнопку `🏠 На главную` пользователь возвращается на главную страницу.

Для администратора имеется специальная команда `/admin_get_data` для извлечения записей из базы данных.
